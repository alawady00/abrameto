# عبرميتو — لعبة الإعراب
ابتكار: أ. عبد الرازق العواضي

- `index.html`: اللعبة كاملة في ملف واحد (ارفعه على GitHub Pages).
- المصدر: `src.html` + `app.js` + `data.js` + `assets/`؛ البناء: `sh build.sh` ثم `node validate.js`.

## تعديل اللعبة (للمالك فقط)
أزرار «+ جملتي» و«تعديل اللعبة» مخفية للزوار. يظهر قفل 🔒 أسفل الواجهة الرئيسية، يدخل منه المالك برمز المالك.
لتغيير الرمز: احسب SHA-256 للرمز الجديد (مثلاً `echo -n 123456 | sha256sum`) وضعه في `OWNER_HASH` داخل `app.js` ثم أعد البناء.
ملاحظة: التعديلات تُحفظ في متصفح المالك فقط؛ لتعميمها على الجميع صدّرها من لوحة التعديل وأرسلها لتُدمج في اللعبة.
